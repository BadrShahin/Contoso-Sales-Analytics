# Project Overview

## Project

Contoso Sales Analytics

---

## Objective

This project demonstrates how to build a production-style Power BI solution using enterprise development practices.

The focus is not only on building reports, but also on applying a complete Git workflow including branching, pull requests, code reviews, version control, and CI/CD concepts.

---

## Goals

- Build a reusable semantic model.
- Develop multiple Power BI reports.
- Apply Git best practices.
- Simulate a multi-developer environment.
- Prepare the project for CI/CD deployment.

---

## Technologies
